Only tiny demo images belong here. All images in this directory are original
synthetic RGB illustrations generated locally by this project, with no external
data or licensing dependencies.

- foundation-demo.png: Phase 0 geometric upload/preview image.
- phase1-street.png: simplified street with a building and car.
- phase1-aerial-rgb.png: aerial-style land, road, water and buildings.
- phase1-objects.png: six colored circles and a white box.
- phase1-spatial.png: labeled shapes in distinct image regions.
- phase1-high-resolution.png: 4096 x 3072 grid used to test resize controls.

The images exercise language and spatial understanding. They are not a scientific
quality benchmark or real remote-sensing data. Large datasets belong in DATASET_DIR.
